A **world-class Flutter application** designed to support expectant mothers throughout their pregnancy journey. Womb Wisdom provides an unprecedented comprehensive suite of features including AI-powered health assistance, government scheme integration, advanced health tracking, telemedicine, e-commerce, and much more.

- **🎮 Gamification System** - Achievements, challenges, and rewards
- **🔒 Enterprise Security** - Biometric auth, 2FA, and data encryption

## 🚀 Getting Started

### **Prerequisites**
- **Flutter SDK** (3.0.0 or higher)
- **Dart SDK** (3.0.0 or higher)
- **Android Studio** / **Xcode** for mobile development
- **Supabase Account** for backend services
- **Git** for version control

### **Installation Steps**

#### 1. Clone the Repository
```bash
git clone https://github.com/MugilMs/Meternal_Care.git
cd Meternal_Care
```

#### 2. Install Dependencies
```bash
flutter pub get
```

#### 3. Configure Supabase
Create `lib/config/supabase_config.dart`:
```dart
class SupabaseConfig {
  static const String supabaseUrl = 'YOUR_SUPABASE_URL';
  static const String supabaseAnonKey = 'YOUR_SUPABASE_ANON_KEY';
}
```

#### 4. Database Setup
```bash
# Run SQL scripts for database schema
cd supabase
# Execute the SQL files in your Supabase dashboard
```

#### 5. Run the Application
```bash
flutter run
```

### **Build for Production**

#### Android
```bash
flutter build apk --release
# or
flutter build appbundle --release
```

#### iOS
```bash
flutter build ios --release
```
